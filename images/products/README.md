# 🖼️ Thư mục chứa hình ảnh sản phẩm (Product Images)

Bạn hãy bỏ các ảnh minh họa mặt hàng của bạn vào thư mục này:
`d:\PRJ\bot-chat\images\products\`

---

## 📌 Các cách đặt tên file ảnh:

### Cách 1: Đặt tên theo ID mặt hàng (Đơn giản nhất)
Hệ thống hỗ trợ các đuôi: `.png`, `.jpg`, `.jpeg`, `.webp`
* `1.png` (hoặc `1.jpg`): Ảnh của mặt hàng ID = 1
* `2.png` (hoặc `2.jpg`): Ảnh của mặt hàng ID = 2
* `3.png` (hoặc `3.jpg`): Ảnh của mặt hàng ID = 3
* `4.png` (hoặc `4.jpg`): Ảnh của mặt hàng ID = 4 (Gmail)
* `5.png` (hoặc `5.jpg`): Ảnh của mặt hàng ID = 5 (Link Netflix)

---

### Cách 2: Đặt tên theo từ khóa gói dịch vụ
* `test_package.png`: Ảnh gói Test hệ thống (2.000đ)
* `chatgpt_plus_warranty.png`: Ảnh gói ChatGPT Plus 1 Tháng (Bảo hành full)
* `chatgpt_plus_no_warranty.png`: Ảnh gói ChatGPT Plus 1 Tháng (Không bảo hành)
* `chatgpt_plus_trial.png`: Ảnh gói Tài khoản ChatGPT có offer trial Plus free 1 tháng
* `gmail.png`: Ảnh gói Gmail Đa Quốc Gia
* `netflix.png`: Ảnh gói Link Netflix (Đăng nhập 1 Click)
* `banner.png`: Ảnh banner chính khi khách bấm xem danh mục sản phẩm

---

💡 **Lưu ý:**
* Nếu bạn chưa bỏ ảnh vào, Bot sẽ **tự động gửi tin nhắn chữ như bình thường** mà không gây bất kỳ lỗi nào.
* Ngay khi bạn copy file ảnh vào thư mục này, Bot sẽ **tự động phát hiện và gửi kèm hình ảnh** vào kịch bản bán hàng!
